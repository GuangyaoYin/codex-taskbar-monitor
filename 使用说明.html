任务栏状态条

Windows 10/11 64 位 · 免安装 · 版本 1.2

解压压缩包后，双击 CodexTaskbarMonitor.exe。程序会在主屏任务栏通知区左侧显示两行数据。开机启动默认关闭。

显示与操作

操作作用
上行CPU、物理内存和选中 GPU 的使用率，每秒刷新。
下行Codex 额度的已用百分比。按接口实际返回的周期显示；周额度不等同于 5 小时额度。
鼠标悬停查看内存容量、GPU 名称、显存、各额度周期的重置时间和最后更新时间。时间按本机时区显示。
左键拖动在当前任务栏空白范围内调整位置，松开后记住。
右键手动刷新额度、切换 GPU、恢复自动位置、选择 Codex 路径、登录、设置开机启动或退出。
托盘入口小窗隐藏时，仍可从系统托盘图标打开详情与菜单。图标可能收在系统的“隐藏图标”区域。

小窗采用圆角、等宽指标列和细进度条，随系统明暗主题调整。右侧两行分别用向下和向上箭头显示下载、上传网速，每秒刷新，按 B/s、KB/s、MB/s 等单位自动换算（每级 1024）。悬停查看当前采集网卡；每次只采一个主联网接口，避免将物理网卡与 VPN 叠加。首次采样、断网或切换接口时显示 --，稳定后的真实零流量显示 0 B/s。

进度条表示已用比例，缺失数据保留空轨道。任务栏隐藏、主屏全屏显示或空白空间不足时，小窗收起，保留托盘入口。程序不修改任务栏或 Explorer；小窗是独立窗口。

Codex 额度

每位用户使用自己安装并登录的官方 Codex。程序自动查找官方桌面附带 CLI、PATH 中的 CLI 及常见安装位置；也可在菜单手动选择 codex.exe。不包含 Codex 运行时、账号或登录凭据。

  1. 没有安装 Codex 时，先阅读 官方 CLI 安装说明，或安装官方 Codex 桌面应用。
  2. 使用 ChatGPT 账号登录 Codex。菜单“登录 Codex”会启动官方登录流程；也可自行在终端运行 codex login。
  3. 回到菜单选择“刷新 Codex 额度”。硬件监控不依赖此登录。

程序只调用 App Server 额度读取接口，不创建对话、不请求模型、不使用额度重置券。正常每两分钟刷新；临时查询失败后按 15、30、60、120 秒自动重试，详情显示下一次重试时刻，也可随时手动重试。接口未返回的周期不会显示为 0%。

下行出现“旧”表示显示的是最后一次成功数据；详情会注明失败状态和更新时间。退出登录、断网、接口变化或 CLI 版本过旧都可能导致查询失败。App Server 仍可能随 Codex 版本变化，需要更新小工具。

硬件数据口径

CPU 取系统忙碌时间比例；内存取物理内存使用率。NVIDIA 优先直接调用已安装驱动的 NVML；其他 GPU 使用 Windows GPU 性能计数器。驱动或硬件不支持时显示 --，详情注明来源；显存容量不可用时不猜测数值。不同 GPU 采集口径可能与任务管理器略有差异。

设置与退出

设置保存在当前用户的 %LOCALAPPDATA%\CodexTaskbarMonitor\settings.json，只包含位置、GPU 选择和用户指定的程序路径。额度数据仅保存在本次运行内存中。启用开机启动后，会在当前用户的 Windows 启动项中记录程序路径；移动程序文件夹后需重新开关此选项。

右键选择“退出”可停止小窗、采集和本工具启动的额度查询子进程。如已开启自启，先关闭“开机启动”，再退出并删除解压文件夹即可移除程序。

兼容性与排查

面向 Windows 10/11 x64，使用系统自带的 .NET Framework，无需安装 Python。建议系统与显卡驱动保持更新。竖向任务栏等暂不支持的布局会保留托盘入口。仅在实际测试过的电脑上验证了行为；其他系统版本及显卡仍需实机验证。

这是独立开发的小工具，当前分发包未进行商业代码签名。若 Windows 提示来源未知，请先核对你信任的分发来源及文件校验值；不要关闭系统安全功能。
