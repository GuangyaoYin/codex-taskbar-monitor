Windows 任务栏硬件与 Codex 额度状态条的首次 GitHub 发布。

- 常驻显示 CPU、物理内存、一张可切换 GPU 的使用率。
- 显示 Codex 实际返回周期的已用额度；悬停查看重置时间及更新时间。
- 圆角、亮暗主题、等宽指标列、细线图标与进度条。
- 支持拖动定位、托盘菜单、手动刷新和可选开机启动。
- 免安装，无需 Python；复用用户自己的官方 Codex 安装与 ChatGPT 登录。

下载 `CodexTaskbarMonitor-1.1.0-win-x64.zip`，解压后双击程序；完整操作说明在压缩包内。

已在 Windows 11 开发机验证。Windows 10 已完成常规任务栏尺寸的几何集成验证，尚未实机验证；AMD 显卡也尚未实测。Codex 未安装或未登录时，硬件监控仍可使用。

分发包不包含 Codex 运行时、登录凭据、用户设置或本机验证日志。
